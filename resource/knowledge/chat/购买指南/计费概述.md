**Choose a monthly plan to get started with Chat.**

Each plan includes Chat’s core capabilities and a usage allowance. Most scenarios won’t incur extra charges. You’ll only see pay‑as‑you‑go fees if you exceed the plan’s included limits or enable paid add‑ons.

### Plan Overview

|Plan|Price|Included MAU|
|---------|---------|---------|
|Free|Free|1,000|
|Standard|$399 / month|10,000|
|Pro|$699 / month|10,000|
|Pro Plus|$1,299 / month|25,000|

## Pricing Components

|Type|Description|Details|
|---------|---------|---------|
|Monthly plan|Core IM features, MAU allowance, groups, and other base resources. **Features vary by plan.**|[Chat Monthly Plans](https://trtc.io/document/67650)|
|Pay‑as‑you‑go overages|MAU, community message delivery volume, text translation, cloud search, cloud push, and server‑side API rate tuning are **billed on demand** when you exceed plan limits or enable paid add‑ons.|[Chat Overage Pricing](https://trtc.io/document/67651)|
|Related products|Audio/Video calling (TRTC) and other products are billed independently.|[TRTC Pricing](https://trtc.io/document/64149)|
