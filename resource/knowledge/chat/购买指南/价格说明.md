## Chat Service Pricing

The Chat service pricing consists of two parts: basic service fee and value-added service fee.

### Basic Service Fee

The basic service fee covers two parts: the **resource plan** fee and **out-of-plan resource usage** fee.
- Resource plan fee: Chat offers the Free Trial, Standard, and Premium editions. The edition for a created application defaults to the Free Trial edition (free). You can choose a plan based on your needs. For resource plan comparison, see [Comparison of billing plans](https://trtc.io/document/67650).

- Out-of-plan resource usage fee: The fee charged for resource usage that exceeds the free quota of the Standard or Premium edition plan.

A user that logs in repeatedly in the same month is considered as one user only for MAU. Use the `login` function appropriately according to business scenarios to avoid an excessively high MAU.

## Content Understanding Service Fee

Content Understanding is a value-added service that analyzes conversation content in the cloud (server side) for Chat scenarios. The pricing details are as follows:
| Capability | Type | Price |
| --- | --- | --- |
| Text Content Understanding | - | 1.5 USD/1,000 messages |
| Audio File Content Understanding | - | 13 USD/1,000 minutes |
| Image Content Understanding | Basic Detection (including pornography, sexually suggestive content, etc.) | 1.5 USD/1,000 images |
| Advertisement Detection | 0.15 USD/1,000 images |  |
| Text and QR Code Recognition | 0.35 USD/1,000 images |  |
| Video File Content Understanding | - | 130 USD/1,000 minutes |

> **Note：**
> - This service uses pay-as-you-go billing. To activate it
> - Duration is measured in seconds. For each SDKAppID, the total duration accumulated each day is converted from seconds to minutes for billing, with any partial minute rounded up to a full minute.
> - When multiple detection capabilities are used on the same image, usage is counted separately for each capability and added up. For example, applying both Image Content Understanding - Basic Detection and Image Content Understanding - Text and QR Code Recognition to the same image counts as two units of usage.
