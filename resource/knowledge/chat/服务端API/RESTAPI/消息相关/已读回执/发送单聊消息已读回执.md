## API Usage Instructions
- App administrators can use this API to send message read receipts for C2C messages.

- When User A sends a C2C message to User B, User B (the recipient) sends a message read receipt. In the request, set the `Operator_Account` field to User B's `UserID`, the `Peer_Account` field to User A's `UserID`, and in the `C2CMsgInfo` array, set `From_Account` to User A's `UserID` and `To_Account` to User B's `UserID`.

### Request URL Example
``` bash
https://xxxxxx/v4/openim/c2c_msg_read_receipt?sdkappid=88888888&identifier=admin&usersig=xxx&random=99999999&contenttype=json
```

### Query Parameters

The table below lists only the parameters relevant to this API call and their descriptions. For more details on other parameters, see the [REST API Overview](https://www.tencentcloud.com/document/product/1047/34620).
| Parameter | Description |
| --- | --- |
| xxxxxx | Region-specific domain for the SDKAppID:<br>- China: <code>console.tim.qq.com</code><br>- Singapore: <code>adminapisgp.im.qcloud.com</code><br>- Seoul: <code>adminapikr.im.qcloud.com</code><br>- Tokyo: <code>adminapijpn.im.qcloud.com</code><br>- Frankfurt: <code>adminapiger.im.qcloud.com</code><br>- Silicon Valley: <code>adminapiusa.im.qcloud.com</code><br>- Jakarta: <code>adminapiidn.im.qcloud.com</code><br>- Riyadh: <code>adminapiksa.im.qcloud.com</code> |
| v4/openim/c2c_msg_read_receipt | API endpoint |
| sdkappid | <code>SDKAppID</code> assigned by the Chat console when creating the application |
| identifier | Must be an App administrator account. For more details, see <a href="https://www.tencentcloud.com/document/product/1047/33517">App Administrator</a> |
| usersig | Signature generated by the App administrator account. For details, see <a href="https://www.tencentcloud.com/document/product/1047/34385">Generate UserSig</a> |
| random | Enter a random 32-bit unsigned integer, range: 0 - 4294967295 |
| contenttype | Request format; fixed value: <code>json</code> |

### Request Example
``` bash
{
    "Operator_Account": "user1",
    "Peer_Account": "user2",
    "C2CMsgInfo": [
        {
            "From_Account": "user2",
            "To_Account": "user1",
            "MsgKey": "1467329515_5675354_1708676941"
        }
    ]
}
```

### Request Fields

|Field|Type|Required|Description|
|---------|---------|---------|---------|
|Operator_Account|String|Required|UserID of the user sending the message read receipt.|
|Peer_Account|String|Required|UserID of the other participant in the conversation.|
|C2CMsgInfo|Array|Required|List of messages for which the message read receipt is being sent.|
|From_Account|String|Required|UserID of the message sender. Must match `Peer_Account`.|
|To_Account|String|Required|UserID of the message recipient. Must match `Operator_Account`.|
|MsgKey|String|Required|Unique identifier for the message.|

#### Response Example
``` bash
{
    "ActionStatus": "OK",
    "ErrorInfo": "",
    "ErrorCode": 0
}
```

### Response Fields
| Field | Type | Description |
| --- | --- | --- |
| ErrorCode | Integer | Error code:<br>- 0 indicates success.<br>- Non-zero indicates failure. |
| ErrorInfo | String | Error message. |
| ActionStatus | String | Status of the request processing. |
