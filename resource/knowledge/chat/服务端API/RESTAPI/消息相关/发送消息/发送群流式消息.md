## Overview

This API enables an account to send G2C (Group Chat) streaming messages to a group. Typical use cases include real-time AI assistant responses, delivering large text blocks token by token, and scenarios where content is generated and displayed incrementally.
- The API supports chunked messaging, allowing content to be sent in multiple fragments, which clients can receive progressively.

- The API does not validate whether the sender is muted.

   > **Note:**
   > 
   > - **Message Size:**
   > - The maximum size for a single streaming message is **128 KB**. This is the combined total size of all chunks for one streaming message, not the size per chunk.
   > - **Send Rate:**
   > - The maximum rate for chunk continuation requests within the same stream is **5 times per second**. If you exceed this rate, the server returns error code **90315** (Request rate exceeded) and rejects the request.
   > - We recommend aggregating chunks by time window: combine tokens received within every **200 ms** window into a single chunk before sending (to comply with the 5 times/sec limit).
   > - **Stream Termination Rules:**
   > - Active termination: Send a chunk with **IsLast=true** to immediately mark the stream as completed.
   > - Timeout termination: The interval between two consecutive chunks must not exceed **15 seconds**. If a timeout occurs, the server automatically appends a termination chunk with **IsLast=true** to finalize the stream.
   > - Once a stream is terminated, it cannot be resumed. Continuation requests for this stream return error code **90318** (Stream completed, no further chunks accepted). To continue sending content, initiate a new streaming message.

## API Description

### Request URL Example
``` bash
https://xxxxxx/v4/stream_msg/send_group_stream_msg?sdkappid=88888888&identifier=admin&usersig=xxx&random=99999999&contenttype=json
```

### Query Parameters

The table below lists only the parameters relevant to this API call. For additional parameters, see REST API Overview.
| Parameter | Description |
| --- | --- |
| xxxxxx | Dedicated domain for the country/region of your <code>SDKAppID</code>:<br>- China: <code>console.tim.qq.com</code><br>- Singapore: <code>adminapisgp.im.qcloud.com</code><br>- Tokyo: <code>adminapijpn.im.qcloud.com</code><br>- Frankfurt: <code>adminapiger.im.qcloud.com</code><br>- Other data centers are not supported. |
| v4/stream_msg/send_group_stream_msg | API endpoint. |
| sdkappid | <code>SDKAppID</code> assigned in the Chat console when you create the application. |
| identifier | Must be an App administrator account. . |
| usersig | Signature generated by the App administrator account. . |
| random | A random 32-bit unsigned integer in the range 0 - 4294967295. |
| contenttype | Request format, fixed value: <code>json</code>. |

### API Rate Limits
- Default API rate limit: 200 requests per second.

- Trial Edition and Development Edition daily limit: 1000 messages per day.

### Request Example

#### Sending the Initial Group Streaming Message Chunk
``` json
{
    "GroupId": "group_123456",
    "Random": 1287657,
    "MsgBody": [
        {
            "MsgType": "TIMStreamElem",
            "MsgContent": {
                "CompatibleText": "The current version is too low, please upgrade to view streaming messages",
                "Chunks": [
                    {
                        "EventType": "data",
                        "Index": 1,
                        "Markdown": "Hello, this is the first fragment of the streaming message",
                        "IsLast": false
                    }
                ]
            }
        }
    ],
    "CloudCustomData": "your cloud custom data"
}
```

#### Continuing to Send Group Streaming Message Chunks
``` json
{
    "GroupId": "group_123456",
    "Random": 1287657,
    "MsgBody": [
        {
            "MsgType": "TIMStreamElem",
            "MsgContent": {
                "StreamMsgID": "stream_msg_id_from_first_response",
                "Chunks": [
                    {
                        "EventType": "data",
                        "Index": 2,
                        "Markdown": " - Continued content",
                        "IsLast": false
                    },
                    {
                        "EventType": "data",
                        "Index": 3,
                        "Markdown": " - Last chunk",
                        "IsLast": true
                    }
                ]
            }
        }
    ]
}
```

### Request Fields
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| GroupId | String | Required | Group ID that identifies the group receiving the message. |
| From_Account | Integer | Optional | The sender's UserID (specifies the account sending the message). If omitted, the message is sent by the system administrator. |
| Random | Integer | Required | Random number (32-bit unsigned integer) used by the backend for deduplication within the same second. Ensure this field is set to a random value. |
| SendMsgControl | Array | Optional | Message send control options. This is a string array that applies only to this message.<br>- <code>NoUnread</code>: Message does not count toward unread messages.<br>- <code>NoLastMsg</code>: Message does not update the conversation list.<br>- <code>NoMsgCheck</code>: Message is not subject to Cloud Moderation when enabled. |
| MsgBody | Array | Required | Message content. Must include a <code>TIMStreamElem</code> element. |
| MsgType | String | Required | Streaming messages must use <code>TIMStreamElem</code>. |
| MsgContent | Object | Required | Streaming message content object. See the <code>StreamMsgContent</code> structure below. |
| CloudCustomData | String | Optional | Custom message data (stored in the cloud, sent to the peer, and retrievable after app uninstall/reinstall). |
| NeedReadReceipt | Integer | Optional | Specifies whether the message requires a read receipt:<br>- 0: Not required.<br>- 1: Required.<br>- Default: 0. |
| OfflinePushInfo | Object | Optional | Offline Push information configuration. . |

### StreamMsgContent Fields

|Field|Type|Required|Description|
|---------|---------|---------|---------|
|CompatibleText|String|Optional|Compatibility prompt text. Default: "The current version is too low, please upgrade to view streaming messages".|
|StreamMsgID|String|Optional|Not required for the first streaming message. Must be included for continuation streams (value returned in the initial response).|
|Chunks|Array|Required|Streaming message chunk array. See the `StreamChunk` structure below.|

### StreamChunk Fields
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| EventType | String | Required | Chunk type:<br>- <code>data</code>: AI reply streaming content or standard data. |
| Index | Integer | Required | Chunk index, starting from 1 and strictly incrementing. |
| Markdown | String | Optional | Streaming Markdown content. |
| IsLast | Boolean | Required | Indicates whether this is the last chunk. The final chunk must have <code>IsLast=true</code>. |

### Response Example
- Successful response (first message chunk):

   ``` json
   {
     "ActionStatus": "OK",
     "ErrorInfo": "",
     "ErrorCode": 0,
     "StreamMsgID": "stream_group_1234567890_abcdef",
     "MsgSeq": 123456789               
   }
   ```
- Error response:

   ``` json
   {
     "ActionStatus": "FAIL",
     "ErrorInfo": "Streaming message format error",
     "ErrorCode": 90300
   }
   ```

### Response Fields
| Field | Type | Description |
| --- | --- | --- |
| ActionStatus | String | Request status:<br>- OK: Success.<br>- FAIL: Failure. |
| ErrorCode | Integer | Error code:<br>- 0: Success.<br>- Non-zero: Failure. |
| ErrorInfo | String | Error message. |
| StreamMsgID | String | Unique identifier for the streaming message, used for continuation. |
| MsgSeq | Integer | Message sequence number. |

## Error Codes

Unless a network error occurs (such as a 502 error), the HTTP response code for this API is always 200. Specific error codes and messages are provided in the response body via `ErrorCode` and `ErrorInfo`.

For common error codes (60000 to 79999).
