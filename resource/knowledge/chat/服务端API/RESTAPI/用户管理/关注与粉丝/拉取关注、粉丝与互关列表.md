## Feature Description

Paged pull of fans/follows/mutual followers list for designated users.

> **Notes:**
> 
> Note: To use the follow feature, purchase [Pro, Pro Plus, or Enterprise Edition](https://trtc.io/document/67650), then enable it in [**Console**](https://console.trtc.io/chat/) > **Configuration** > **Friends and Relationship Chains** > **Follow / Fan function settings** page.
> 

## API Call Description

### Sample Request URL
``` bash
https://xxxxxx/v4/follow/follow_get?sdkappid=88888888&identifier=admin&usersig=xxx&random=99999999&contenttype=json
```

### Request Parameters

The following table describes the modified parameters when this API is called. For other parameters, see [RESTful API Overview](https://trtc.io/document/34620).
| Parameter | Description |
| --- | --- |
| xxxxxx | Domain name corresponding to the country/region where your SDKAppID is located.<br>- China: <code>console.tim.qq.com</code><br>- Singapore: <code>adminapisgp.im.qcloud.com</code><br>- Seoul: <code>adminapikr.im.qcloud.com</code><br>- Tokyo: <code>adminapijpn.im.qcloud.com</code><br>- Frankfurt: <code>adminapiger.im.qcloud.com</code><br>- Silicon Valley: <code>adminapiusa.im.qcloud.com</code><br>- Jakarta: <code>adminapiidn.im.qcloud.com</code><br>- Riyadh: <code>adminapiksa.im.qcloud.com</code> |
| v4/follow/follow_get | Request API. |
| sdkappid | SDKAppID assigned by the Chat console when an app is created. |
| identifier | App admin account. For more information, see the <strong>App Admin</strong> section in <a href="https://trtc.io/document/33517?platform=javascript&product=chat&menulabel=coresdk">Login Authentication</a>. |
| usersig | Signature generated by the app admin account. For details, see <a href="https://trtc.io/document/34385?product=chat&menulabel=serverapi">Generating UserSig</a>. |
| random | A random 32-bit unsigned integer ranging from 0 to 4294967295. |
| contenttype | Request format, which should always be <code>json</code>. |

### Maximum Calling Frequency

200 times/second.

### Sample Requests
``` json
{
  "From_Account": "UserID_001",
  "FollowType": 1,
  "StartCursor": "",
  "WantNum": 100
}
```

### Request Fields
| Field | Type | Attribute | Description |
| --- | --- | --- | --- |
| From_Account | String | Required | User's UserID. |
| FollowType | Integer | Required | Type to be pulled:<br>- 1 - Fan<br>- 2 - Follow<br>- 3 - Mutual follow |
| StartCursor | String | Required | Start position for paging: Empty on homepage, fill in the NextCursor field returned in the previous page's response for subsequent requests. |
| WantNum | Integer | Required | Number of entries to fetch: Default returns 100 entries per page, supports up to 1000 entries. |

| Field | Type | Description |
| --- | --- | --- |
| FollowItem | Array | Fans/Follows/Mutual Followers List. |
| To_Account | String | User's UserID of fans/followers/mutual followers |
| FollowTime | Integer | Focus on time. |

## Error Codes

The returned HTTP status code for this API is always 200 unless a network error (such as error 502) occurs. The specific error code and details can be found in the response fields `ErrorCode` and `ErrorInfo` respectively.

For public error codes (60000 to 79999), please see [Error Codes](https://trtc.io/document/34348).

The following table describes the error codes specific to this API:

|Error Code|Description|
|---------|---------|
|30001|Request parameter error. Please check the request parameters according to the error description.|
|30002|SDKAppID does not match.|
|30003|Requested user account does not exist.|
|30004|Request requires App administrator permissions.|
|30005|This application does not have the fan and follow feature enabled. To use it, purchase [Pro, Pro-plus, or Enterprise Edition](https://trtc.io/document/67650) and activate it in the [Console](https://console.trtc.io/chat/).|
|30006|Server internal error, please try again.|
|30007|Network timeout. Please try again later.|
