## Feature Overview

This API is used by the app administrator to obtain the list information of all official channels subscribed by a user.

> **Note:**
> The feature is only available for Enterprises. To enable it You can [trial](https://trtc.io/document/34577) this feature in the console. The trial version allows creating up to 5 public accounts, valid for one month.
> 

## API Calling Description

### Sample Request URL
``` https
https://xxxxxx/v4/official_account_open_http_svc/get_subscribed_official_account_list?sdkappid=88888888&identifier=admin&usersig=xxx&random=99999999&contenttype=json
```

### Request Parameters

The table below only lists the parameters modified when this API is called and their descriptions. For details on the parameters, refer to [RESTful API Overview](https://www.tencentcloud.com/document/product/1047/34620).
| Parameter | Description |
| --- | --- |
| xxxxxx | Domain name corresponding to the country/region where your SDKAppID is located.<br>- China: <code>console.tim.qq.com</code><br>- Singapore: <code>adminapisgp.im.qcloud.com</code><br>- Seoul: <code>adminapikr.im.qcloud.com</code><br>- Tokyo: <code>adminapijpn.im.qcloud.com</code><br>- Frankfurt: <code>adminapiger.im.qcloud.com</code><br>- Silicon Valley: <code>adminapiusa.im.qcloud.com</code><br>- Jakarta:  <code>adminapiidn.im.qcloud.com</code><br>- Riyadh: <code>adminapiksa.im.qcloud.com</code> |
| v4/official_account_open_http_svc/get_subscribed_official_account_list | Request API. |
| sdkappid | The SDKAppID assigned by the Chat console when an application is created. |
| identifier | The app admin account. For details, see <a href="https://www.tencentcloud.com/document/product/1047/33517#app-.E7.AE.A1.E7.90.86.E5.91.98">App Admin</a>. |
| usersig | The signature generated by the app admin account. For details, see <a href="https://www.tencentcloud.com/document/product/1047/34385">Generating UserSig</a>. |
| random | A random 32-bit unsigned integer ranging from 0 to 4294967295. |
| contenttype | The value is always <code>json</code>. |

### Maximum Call Frequency

200 times/second

### Sample Request Packets
``` json
{
   "Subscriber_Account": "107867", 		//Subscriber
   "Limit": 200,		
   "Offset": 0,
   "ResponseFilter":{		//Filter fields
      "OfficialAccountBaseInfoFilter":[	//Filter fields for official channel information	
            "CreateTime",
            "Name",
            "Owner_Account",
            "LastMsgTime",
            "SubscriberNum",
            "Introduction",
            "FaceUrl",
            "Organization",
            "CustomString"
      ],
      "SelfInfoFilter":[		//Filter fields for subscriber information
            "SubscribeTime",
            "CustomString"
      ]
   }
}
```

### Request Fields
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| Subscriber_Account | String | Yes | ID of the subscriber whose information is to be obtained. |
| Limit | Integer | No | Number of official channels pulled in a single pull, currently supporting a maximum value of 200. If not specified, the default is 200. |
| Offset | Integer | No | Indicates starting pulling from which official channel. |
| ResponseFilter | Object | No | Includes two filters: OfficialAccountBaseInfoFilter and SelfInfoFilter.<br>- OfficialAccountBaseInfoFilter: Indicates the basic information fields of official channels to be pulled, mainly including:<br>- CreateTime: creation time of the official channel<br>- Name: name of the official channel<br>- Owner_Account: user who owns the official channel<br>- LastMsgTime: time of the last message within the official channel<br>- SubscriberNum: current number of subscribers to the official channel<br>- Introduction: introduction to the official channel<br>- FaceUrl: avatar URL of the official channel<br>- Organization: organization of the official channel<br>- CustomString: custom field at the official channel level<br>If not specified, all fields will be pulled.<br>- SelfInfoFilter: Indicates the need to pull subscriber's own information, mainly including:<br>- SubscribeTime: time when the subscriber subscribed to the official channel<br>- CustomString: custom field at the subscriber level<br>If not specified, all fields will be pulled. |

``` json
    "Next": 0		//If the pull has ended, returns 0.

```

### Response Fields
| Field | Type | Description |
| --- | --- | --- |
| ActionStatus | String | Processing result:<br>- OK: succeeded.<br>- FAIL: failed. |
| ErrorCode | Integer | Error code:<br>- 0: succeeded.<br>- Other values: failed. |
| ErrorInfo | String | Error information. |
| OfficialAccountInfoList | Array | The official channel information obtained. The results are filtered information based on the filter fields set in the filter. |
| TotalCount | Integer | Number of official channels subscribed by the user. |
| CompleteFlag | Integer | Indicates whether the pull has ended.<br>- 1: The pull has ended.<br>- 0: The pull has not ended. |
| Next | Integer | Indicates the next pull. If the current pull has not ended, please use the value of Next as the Offset field value in the next request to continue pulling. |

## Error Codes

Unless a network error (such as error 502) occurs, the HTTP return code for this API is always 200. ErrorCode and ErrorInfo in the response packets represent the actual error code and error information.
For common error codes (60000 to 79999), see [Error Codes](https://www.tencentcloud.com/document/product/1047/34348).
The following table describes the error codes specific to this API:

|Error Code|Description|
|---------|---------|
|6017|Invalid request parameter. Please modify and retry.|
|10004|Internal server error. Please try again.|
|20001|Invalid request packet. Please modify and retry.|
|20005|Internal server error. Please try again.|
|130002|Insufficient operation permissions. Please check the request parameters based on the error message.|
|130004|The official channel user does not exist, or once existed but has now been terminated.|
|130007|Incorrect official channel user ID. Please modify and retry.|
|131000|This AppId has not been enabled with official channel service.|
