## Feature Overview

This API is used by the app administrator to terminate an official channel.

> **Note:**
> The feature is only available for Enterprises. To enable it You can [trial](https://trtc.io/document/34577) this feature in the console. The trial version allows creating up to 5 public accounts, valid for one month.
> 

## API Calling Description

### Sample Request URL
``` https
https://xxxxxx/v4/official_account_open_http_svc/destroy_official_account?sdkappid=88888888&identifier=admin&usersig=xxx&random=99999999&contenttype=json
```

### Request Parameters

The table below only lists the parameters modified when this API is called and their descriptions. For details on the parameters, refer to [RESTful API Overview](https://www.tencentcloud.com/document/product/1047/34620).
| Parameter | Description |
| --- | --- |
| xxxxxx | Domain name corresponding to the country/region where your SDKAppID is located.<br>- China: <code>console.tim.qq.com</code><br>- Singapore: <code>adminapisgp.im.qcloud.com</code><br>- Seoul: <code>adminapikr.im.qcloud.com</code><br>- Tokyo: <code>adminapijpn.im.qcloud.com</code><br>- Frankfurt: <code>adminapiger.im.qcloud.com</code><br>- Silicon Valley: <code>adminapiusa.im.qcloud.com</code><br>- Jakarta:  <code>adminapiidn.im.qcloud.com</code><br>- Riyadh: <code>adminapiksa.im.qcloud.com</code> |
| v4/official_account_open_http_svc/destroy_official_account | Request API. |
| sdkappid | The SDKAppID assigned by the Chat console when an application is created. |
| identifier | The app admin account. For details, see <a href="https://www.tencentcloud.com/document/product/1047/33517#app-.E7.AE.A1.E7.90.86.E5.91.98">App Admin</a>. |
| usersig | The signature generated by the app admin account. For details, see <a href="https://www.tencentcloud.com/document/product/1047/34385">Generating UserSig</a>. |
| random | A random 32-bit unsigned integer ranging from 0 to 4294967295. |
| contenttype | The value is always <code>json</code>. |

### Maximum Call Frequency

200 times/second

### Sample Request Packets
``` json
{
    "Official_Account": "@TOA#_test_id"	
}
```

### Request Fields

|Field|Type|Required|Description|
|---------|---------|---------|---------|
|Official_Account|String|Yes|The ID of the official channel to be terminated. Use the OfficialAccountUserID field returned by the API during creation.|

### Sample Response Packets
``` json
{
   "ActionStatus": "OK",
   "ErrorInfo": "",
   "ErrorCode": 0
}
```

### Response Fields
| Field | Type | Description |
| --- | --- | --- |
| ActionStatus | String | Processing result:<br>- OK: succeeded.<br>- FAIL: failed. |
| ErrorCode | Integer | - Error code:<br>- 0: succeeded.<br>- Other values: failed. |
| ErrorInfo | String | Error information. |

## Error Codes

Unless a network error (such as error 502) occurs, the HTTP return code for this API is always 200. ErrorCode and ErrorInfo in the response packets represent the actual error code and error information.
For common error codes (60000 to 79999), see [Error Codes](https://www.tencentcloud.com/document/product/1047/34348).
The following table describes the error codes specific to this API:

|Error Code|Description|
|---------|---------|
|6017|Invalid request parameter. Please modify and retry.|
|10004|Internal server error. Please try again.|
|20001|Invalid request packet. Please modify and retry.|
|20005|Internal server error. Please try again.|
|130002|Insufficient operation permissions. Please check the request parameters based on the error message.|
|130004|The official channel user does not exist, or once existed but has now been terminated.|
|130007|Incorrect official channel user ID. Please modify and retry.|
|130008|The official channel user ID is already in use. Please modify and retry.|
|131000|This AppId has not been enabled with official channel service. Please enable it and retry.|
