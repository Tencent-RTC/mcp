## Feature Overview

App admins can call this API to modify the topic permissions in a permission group.

## API Calling Description

### Applicable Group Types

|Group Type|Whether This RESTful API Is Supported|
|---------|---------|
|Private|Not supported, same as Work (Work Friend Group) in the new version.|
|Public|Not supported.|
|ChatRoom|Not supported, same as Meeting (Temporary Meeting Group) in the new version.|
|AVChatRoom|Not supported.|
|Community|Supported.|

Chat provides the aforementioned four types of groups. For details, refer to [Group System](https://www.tencentcloud.com/document/product/1047/33529).

### Sample Request URL
``` bash
https://xxxxxx/v4/group_open_http_svc/set_topic_permission_group?sdkappid=88888888&identifier=admin&usersig=xxx&random=99999999&contenttype=json
```

### Request Parameters

The table below only lists the parameters modified when calling this API and their descriptions. For details on the parameters, refer to [RESTful API Overview](https://www.tencentcloud.com/document/product/1047/34620).
| Parameter | Description |
| --- | --- |
| xxxxxx | The dedicated domain name for the country/region where your SDKAppID is located:<br>- China: <code>console.tim.qq.com</code><br>- Singapore: <code>adminapisgp.im.qcloud.com</code><br>- Seoul: <code>adminapikr.im.qcloud.com</code><br>- Tokyo: <code>adminapijpn.im.qcloud.com</code><br>- Frankfurt: <code>adminapiger.im.qcloud.com</code><br>- Silicon Valley: <code>adminapiusa.im.qcloud.com</code><br>- Jakarta: <code>adminapiidn.im.qcloud.com</code><br>- Riyadh: <code>adminapiksa.im.qcloud.com</code> |
| v4/group_open_http_svc/set_topic_permission_group | Request API. |
| sdkappid | SDKAppID assigned by the Chat console when an app is created. |
| identifier | You must be an app admin account. For details, refer to <a href="https://www.tencentcloud.com/document/product/1047/33517#app-.E7.AE.A1.E7.90.86.E5.91.98">App Admins</a>. |
| usersig | The signature generated by the app admin account. For details, refer to <a href="https://www.tencentcloud.com/document/product/1047/34385">Generating UserSig</a>. |
| random | A random 32-bit unsigned integer ranging from 0 to 4294967295. |
| contenttype | Request format fixed value: <code>json</code>. |

### Maximum Calling Frequency

200 queries/sec.

### Sample Request Packet
- Modify topic permissions in a permission group

   ``` bash
   {
       "GroupId": "@TGS#_@TGS#cV6IHIIM62C4",
       "PermissionGroupId": "@PMG#_test_permission_group_with_topic",
       "TopicPermissionList": [
           {
               "Permission": 123456,
               "TopicId": "@TGS#_@TGS#cV6IHIIM62C4@TOPIC#_@TOPIC#cTEJHIIM62CJ"
           }
       ]
   }
   ```

### Description of Request Packet Fields

|Field|Type|Attribute|Description|
|---------|---------|---------|---------|
|GroupId|String|Required|Group ID.|
|PermissionGroupId|String|Required|Permission group ID.|
|TopicPermissionList|Array|Required|The topic permissions added cannot exceed 50 in one request.|
|TopicId|String|Required|Added topic ID.|
|Permission|Integer|Required|Similar to the permission bits of a permission group, each bit of topic permissions represents a specific permission. For specific permission bit descriptions.|

### Sample Response Packet
``` bash
{
    "ActionStatus": "OK",
    "ErrorInfo": "",
    "ErrorCode": 0,
    "TopicPermissionResultList": [
        {
            "ErrorCode": 0,
            "ErrorInfo": "",
            "TopicId": "@TGS#_@TGS#cV6IHIIM62C4@TOPIC#_@TOPIC#cTEJHIIM62CJ"
        }
    ],
    "RequestId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
}
```

### Description of Response Packet Fields
| Field | Type | Description |
| --- | --- | --- |
| ActionStatus | String | Result of the request processing:<br>- OK: Indicates successful processing.<br>- FAIL: Indicates failure. |
| ErrorCode | Integer | Error code:<br>- 0: Indicates success.<br>- Non-zero: Indicates failure. |
| ErrorInfo | String | Error message. |
| TopicPermissionResultList | Array | The result of the added topic permissions. Each item represents a result. Only when the ErrorCode is 0, it indicates a successful modification. |
| RequestId | String | Unique identifier for the current request. |

## Error Codes

Unless a network error (such as a 502 error) occurs, the HTTP return code for this API is always 200. The real error code and error message are indicated by ErrorCode and ErrorInfo in the response packet body.
Common error codes (60000 to 79999) can be found in the [Error Codes](https://www.tencentcloud.com/document/product/1047/34348) document.
The private error codes for this API are as follows:

|Error Code|Description|
|---------|---------|
|10002|Internal server error. Try again.|
|10003|Illegal request command word.|
|10004|Invalid parameter. Check if the request is correct based on the error description.|
|10007|Insufficient operation permissions, such as lacking the permission to modify the topic permissions.|
|10010|The group does not exist, or it existed in the past but has now been dissolved.|
|10015|Invalid group ID. Check if the group ID is filled in correctly.|
|10016|The developer backend has denied this operation through third-party callback.|
|110006|The permission group does not exist, or it existed in the past but has now been dissolved.|
|110008|Invalid permission group ID. Check if the permission group ID is filled in correctly.|
|110011|Topic permissions do not exist.|
