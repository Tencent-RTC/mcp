## Feature Overview

You can use this API to get the list of banned members of an audio-video group.

> **Note:**
> Audio-video group member banning is supported by SDK Enhanced edition v6.6 or later and web SDK v2.22.0 or later. To use it, you need to [purchase the Pro edition, Pro Plus edition or Enterprise edition](https://www.tencentcloud.com/document/product/1047/34577), go to the [console](https://console.trtc.io/chat/qun-setting), choose **Feature configuration** > **Group configuration** > **Group feature configuration**, and enable **Audio-video group member banning**.
> 

## API Calling Description

### Applicable group types

|Group Type ID|RESTful API Support|
|---------|---------|
|Private|Yes. Same as work groups (Work) in the new version.|
|Public|Yes.|
|ChatRoom|Yes. Same as meeting groups (Meeting) in the new version.|
|AVChatRoom|Yes.|
|Community|Yes.|

These are the preset group types in Chat. For more information, see [Group System](https://intl.cloud.tencent.com/document/product/1047/33529).

### Sample request URL
``` bash
https://xxxxxx/v4/group_open_http_svc/get_group_ban_member?sdkappid=88888888&identifier=admin&usersig=xxx&random=99999999&contenttype=json
```

### Request parameters

The following table describes the modified parameters when this API is called. For other parameters, see [RESTful API Overview](https://intl.cloud.tencent.com/document/product/1047/34620).
| Parameter | Description |
| --- | --- |
| xxxxxx | Domain name corresponding to the country/region where your SDKAppID is located.<br>- China: <code>console.tim.qq.com</code><br>- Singapore: <code>adminapisgp.im.qcloud.com</code><br>- Seoul: <code>adminapikr.im.qcloud.com</code><br>- Tokyo: <code>adminapijpn.im.qcloud.com</code><br>- Frankfurt: <code>adminapiger.im.qcloud.com</code><br>- Silicon Valley: <code>adminapiusa.im.qcloud.com</code><br>- Jakarta: <code>adminapiidn.im.qcloud.com</code><br>- Riyadh: <code>adminapiksa.im.qcloud.com</code> |

| sdkappid | SDKAppID assigned by the Chat console when an app is created. |

| contenttype | Request format. The value is fixed to <code>json</code>. |

### Maximum call frequency

200 calls per second.

### Sample request
- **Basic format**

   It is used to deliver broadcast messages to all the audio-video groups.

   ``` bash
   {
       "GroupId": "@TGS#aJRGC4MH6",  // Group ID
       "Limit":20, // Number of banned members to be pulled per page each time. The maximum value allowed is 100.
       "Offset": 0 // Offset. For the first request, set `Offset` to 0. For subsequent requests, set `Offset` to the value of `NextOffset` in the response packet. If `NextOffset` is 0, the entire list of banned members of the audio-video group is obtained.
   }
   ```

### Request fields

|Field|Type|Required|Description|
|---------|---------|---------|---------|
|GroupId|String|Yes|ID of the group whose members are to be unbanned.|
|Limit|Integer|No|Number of unbanned users to be obtained each time. The maximum value allowed is 100.|
|Offset|Integer|Yes|Offset. For the first request, set `Offset` to 0. For subsequent requests, set `Offset` to the value of `NextOffset` in the response packet.|

### Sample response
``` bash
{
    "ActionStatus": "OK",
    "BannedAccountList": [
        {
            "BannedUntil": 1660875916,
            "Member_Account": "brennanli1"
        },
        {
            "BannedUntil": 1660875916,
            "Member_Account": "brennanli12"
        }
    ],
    "ErrorCode": 0,
    "ErrorInfo": "",
    "NextOffset": 2,
    "RequestId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
}
```

### Response fields
| Field | Type | Description |
| --- | --- | --- |
| ActionStatus | String | Request result:<br>- OK: successful;<br>- FAIL: failed. |
| ErrorCode | Integer | Error code:<br>- 0: Successful;<br>- Other values: Failed. |
| ErrorInfo | String | Error information. |
| BannedAccountList | Array | Information of banned members. <code>BannedUntil</code> indicates the banning end time of banned members. <code>Member_Account</code> indicates the account IDs of banned members. |
| NextOffset | Integer | Offset value of the next request. If this field is <code>0</code>, the list of banned members of the AVChatRoom group is fully pulled. |
| RequestId | String | Unique identifier for the current request. |

## Error Codes

The returned HTTP status code for this API is always 200 unless a network error (such as error 502) occurs. The specific error code and details can be found in the response fields `ErrorCode` and `ErrorInfo` respectively.
For public error codes (60000 to 79999), see [Error Codes](https://intl.cloud.tencent.com/document/product/1047/34348).
The following table describes the error codes specific to this API:

|Error Code|Description|
|---------|---------|
|10002|Internal server error. Try again.|
|10003|Invalid command word.|
|10004|Invalid parameter. Check the error description and troubleshoot the issue.|
|10007|Insufficient operation permissions. For example, the switch is not enabled in the console, or the operating account is not the root account.|
