## Feature Description

The app admin can use the group ID to obtain the number of online users in a live stream group.

## API Description

### Applicable group types

|Group Type ID|REST API Support|
|---------|---------|
|Private|Yes. Same as Work (work group) in the new version.|
|Public|Yes.|
|ChatRoom|Yes. Same as Meeting (temporary meeting group) in the new version.|
|AVChatRoom|Yes.|
|Community|Yes.|

Above are the IM built-in groups. For more information, see [Group system](https://intl.cloud.tencent.com/document/product/1047/33529).

> **Note:**
> - The number of online users is updated every 10s.
> - When there are web users, the number of online users will be updated 10s to 20s after a user joins or quits the group.
> - Private, Public, ChatRoom, and Community groups require [Pro edition, Pro Plus edition or Enterprise edition Package](https://buy.cloud.tencent.com/avc), and the "Group Member Online Status" feature must be activated (via "Group Feature Configuration" in the console).

### Sample request URL
``` bash
https://xxxxxx/v4/group_open_http_svc/get_online_member_num?sdkappid=88888888&identifier=admin&usersig=xxx&random=99999999&contenttype=json
```

### Request parameters

The following table only describes the modified parameters when this API is called. For more information on other parameters, please see [RESTful API Overview](https://intl.cloud.tencent.com/document/product/1047/34620).
| Parameter | Description |
| --- | --- |
| https | The request protocol is HTTPS, and the request method is POST. |
| xxxxxx | The country/region where your SDKAppID is located.<br>- China:  <code>console.tim.qq.com</code><br>- Singapore:  <code>adminapisgp.im.qcloud.com</code><br>- Seoul: <code>adminapikr.im.qcloud.com</code><br>- Tokyo: <code>adminapijpn.im.qcloud.com</code><br>- Frankfurt: <code>adminapiger.im.qcloud.com</code><br>- Silicon Valley: <code>adminapiusa.im.qcloud.com</code><br>- Jakarta: <code>adminapiidn.im.qcloud.com</code><br>- Riyadh: <code>adminapiksa.im.qcloud.com</code> |
| v4/group_open_http_svc/get_online_member_num | The API to which the request is sent. |
| sdkappid | The SDKAppID assigned by the IM console when an application is created. |
| identifier | Must be the app admin account. For more information, please see the <strong>App Admin</strong> section in <a href="https://intl.cloud.tencent.com/document/product/1047/33517">Login Authentication</a>. |
| usersig | The signature generated by the app admin account. For more information on the operation, please see <a href="https://intl.cloud.tencent.com/document/product/1047/34385">Generating UserSig</a>. |
| random | A random 32-bit unsigned integer ranging from 0 to 4294967295. |
| contenttype | Request format. The value is always <code>json</code>. |

### Maximum call frequency

200 times/second.

### Sample request packet

This API is used to obtain the number of online users in a live stream group (AVChatRoom). The number of online users is updated every 10s. We recommend that the service-end queries the number of online users every 10s and synchronizes it to all users in the group.
``` bash
{
    "GroupId":"@TGS#a6I4ZUUGO"
}
```

### Request packet fields

|Field|Type|Required|Description|
|---------|---------|---------|---------|
|GroupId|String|Yes|The group ID.|

### Sample response packet
``` bash
{
    "ActionStatus":"OK",
    "ErrorInfo":"", 
    "ErrorCode": 0, 
    "OnlineMemberNum":1000, // Number of online users
    "RequestId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
}
```

### Response packet fields
| Field | Type | Description |
| --- | --- | --- |
| ActionStatus | String | The request result:<br>- OK: succeeded.<br>- FAIL: failed. |
| ErrorCode | Integer | The error code:<br>- 0: succeeded.<br>- Other values: failed. |
| ErrorInfo | String | The error information. |
| OnlineMemberNum | Integer | The number of online users in the group. |
| RequestId | String | Unique identifier for the current request. |

## Error Codes

The returned HTTP status code for this API is always 200 unless a network error (such as error 502) occurs. The specific error code and details can be found in the response fields `ErrorCode` and `ErrorInfo` respectively.
For public error codes 60000 to 79999, please see [Error Codes](https://intl.cloud.tencent.com/document/product/1047/34348).
The following table describes the error codes specific to this API.

|Error Code|Description|
|---------|---------|
|10002|A system error occurred. Try again or contact technical support.|
|10003|The request command is invalid. Try again or contact technical support.|
|10004|A parameter is invalid. Check the `ErrorInfo` field in the response packet to see whether the required fields have been specified or whether the fields are set according to protocol requirements.|
|10007|Insufficient permissions. The operator is not an App administrator.|
|10010|The group does not exist or has been disbanded.|
|10015|The group ID is invalid. Please check the group ID.|
