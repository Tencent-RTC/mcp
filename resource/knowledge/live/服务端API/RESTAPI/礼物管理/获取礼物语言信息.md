## Feature Description

The App admin can use this API to retrieve gift language info.

## API Call Description

### Sample Request URL
``` https
https://xxxxxx/v4/live_engine_http_srv/get_gift_language?sdkappid=88888888&identifier=admin&usersig=xxx&random=99999999&contenttype=json
```

### Request Parameters

The following table lists only the parameters involved in modification when calling this API and their descriptions. For more details about the parameters, please .
| Parameter | Description |
| --- | --- |
| xxxxxx | SDKAppID is located in the country/region corresponding to the dedicated domain name:<br>- China: <code>console.tim.qq.com</code><br>- Singapore: <code>adminapisgp.im.qcloud.com</code><br>- Silicon Valley: <code>adminapiusa.im.qcloud.com</code><br>- Jakarta: <code>adminapiidn.im.qcloud.com</code> |
| v4/live_engine_http_srv/get_gift_language | Request API. |
| sdkappid | The SDKAppID assigned by the Chat console when creating an application. |
| identifier | It must be an App administrator account. . |
| usersig | The signature generated by the App administrator account. For specific operations, see Generate UserSig. |
| random | Enter a random 32-bit unsigned integer, value ranges from 0 to 4294967295. |
| contenttype | The request format is fixed as <code>json</code>. |

### Maximum Calling Frequency

1 time/second.

### Sample Request Packet

**Basic form**
``` json
{
    "GiftId":"GId1",
    "Language":"en"
}
```

### Request Packet Fields

|Field|Type|Attribute|Description|
|---------|---------|---------|---------|
|GiftId|String|Required|Gift ID, up to 20 bytes.|
|Language|String|Required|Gift language types, now supported: "en", "zh-Hans", "zh-Hant".|

### Response Package Example

**Basic form**
``` json
{
    "ErrorCode": 0,
    "ErrorInfo": "",
    "ActionStatus": "OK",
    "RequestId": "Id-27cbb1204fc04358a23e519410ae5373-O-Seq-541258",
    "GiftInfo": {
        "Name": "name1",
        "Desc": "desc1"
    }
}
```

### Response Packet Fields

|Field|Type|Description|
|---------|---------|---------|
|ActionStatus|String|Request processing result. OK: processing successful; FAIL: processing failed.|
|ErrorCode|Integer|Error code: 0 indicates success, non-zero indicates failure.|
|ErrorInfo|String|Error message.|
|RequestId|String|Unique request ID, returned for each request. RequestId is required for locating a problem.|
|Name|String|gift name.|
|Desc|String|Gift description.|

## Error Code Description

Unless a network error (such as 502) occurs, the HTTP return code of this API is 200. The actual error code and error information are indicated by ErrorCode and ErrorInfo in the response payload.
