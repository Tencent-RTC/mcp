## Common Types

### CompletionHandler

Returned value of API call.

|Type|Type|Description|
|---------|---------|---------|
|errorCode|int|errorCode 0 means the API call is successful, otherwise errorCode indicates the API call failure error code.|
|errorMessage|String|The causes for API call failure.|

### CallParams

Call parameters.

|Type|Type|Description|
|---------|---------|---------|
|roomId|String|room ID.|
|timeout|int|Timeout duration.|
|userData|String|User-defined data.|
|chatGroupId|String|GroupId|
|isEphemeralCall|bool|Whether anonymous call is enabled. Call records are not saved when enabled. true: enables anonymous calling; false: disables anonymous calling.|

## **Enum Definition**

### CallMediaType

Call media type.

|Type|Description|
|---------|---------|
|audio|Voice call.|
|video|Video call.|
