## TUICallKit (UI Included)

TUICallKit is an audio/video call component that **includes UI elements**. You can use its APIs to quickly implement an audio/video call application.

|API|Description|
|---------|---------|
|login|Log in.|
|[logout](https://www.tencentcloud.com/document/product/647/54906#logout)|Log out.|
|setSelfInfo|Set the user nickname and profile photo.|
|calls|Start a call.|
|join|Join the call.|
|enableMuteMode|Set whether to turn on the mute mode.|
|enableFloatWindow|Set whether to enable floating windows.|
|enableIncomingBanner|Enable/Disable Call Banner|

## Key Type Definition

|Type|Description|
|---------|---------|
|CallMediaType|Call type.|
|CallParams|Call extension parameter.|
|CompletionHandler|Returned value of API call.|
