## Feature Overview

Administrator obtaining application attribute name. Please [Set Application Attribute Name](https://www.tencentcloud.com/document/product/1047/60563) first.

### Sample request URL
``` html
https://xxxxxx/v4/timpush/get_attr_name?usersig=xxx&identifier=admin&sdkappid=88888888&random=99999999&contenttype=json
```

### Request parameters
| Parameter | Description |
| --- | --- |
| https | - Request protocol is HTTPS<br>- Request method is POST |
| xxxxxx | The dedicated domain corresponding to the country/region of your SDKAppID.<br>- China: <code>console.tim.qq.com</code><br>- Singapore: <code>adminapisgp.im.qcloud.com</code><br>- Seoul: <code>adminapikr.im.qcloud.com</code><br>- Tokyo: <code>adminapijpn.im.qcloud.com</code><br>- Frankfurt: <code>adminapiger.im.qcloud.com</code><br>- Silicon Valley: <code>adminapiusa.im.qcloud.com</code><br>- Jakarta: <code>adminapiidn.im.qcloud.com</code><br>- Riyadh: <code>adminapiksa.im.qcloud.com</code> |
| v4/timpush/get_attr_name | Request API |
| usersig | The Signature generated by the App admin account. For details, see <a href="https://www.tencentcloud.com/document/product/1047/34385">Generating UserSig</a> |
| identifier | You must be an App admin account. For more details, see <a href="https://www.tencentcloud.com/document/product/1047/33517">App Admins</a> |
| sdkappid | SdkAppid assigned by the Instant Messaging Console when an application is created |
| random | A random 32-bit unsigned integer ranging from 0 to 4294967295 |
| contenttype | Fixed value: <code>json</code> |

### Call frequency limit

100 times per second.

### Sample request packets
``` json
{}
```

### Request packet fields

No.

### Sample response packets
``` bash
{
    "ActionStatus": "OK",
    "ErrorInfo": "",
    "ErrorCode": 0,
    "AttrNames": {
        "0": "sex",
        "1": "city",
        "2": "country"
    },
    "AttrTypes": {
        "0": 0, 
        "1": 0,
        "2": 1 // Number key 2 corresponds to the attribute "country", which can only be set by account type 1 (the RegistrationID is automatically generated when the push service registration is succ
    }
}
```

### Response packet field description
| Field | Type | Description |
| --- | --- | --- |
| ActionStatus | String | Processed Request Result:<br>- OK: Indicates successful processing<br>- FAIL: Indicates failure |
| ErrorCode | Integer | Error code |
| ErrorInfo | String | Error message |
| AttrNames | Object | Contains multiple key-value pairs. Each pair represents the name corresponding to a specific attribute. For example, "0":"xxx" indicates that the name of attribute 0 is xxx |
| AttrTypes | Object | Containing multiple key-value pairs. Each key-value pair indicates the account type corresponding to the nth attribute.<br>- "0": 0 means the account type of attribute No. 0 is 0 (Chat account type).<br>- "0": 1 means the account type of attribute No. 0 is 1 (RegistrationID automatically generated when the push service registration is successful). |

## Error codes

Unless a network error occurs (e.g., 502 error), the HTTP return code of this interface is always 200.**The actual error code and error message are indicated by ErrorCode and ErrorInfo in the response payload.**. For public error codes (60000 to 79999), refer to the [Error Codes](https://cloud.tencent.com/document/product/269/1671) documentation.
The private error codes for this API are as follows:

|Error code|Description|
|---------|---------|
|90001|Failed to parse the JSON format. Please ensure the request packet conforms to the JSON specification.|
|90009|The request requires App Administrator permissions.|
|90018|The number of requested accounts exceeds the limit.|
|91000|Internal service error, please try again.|
