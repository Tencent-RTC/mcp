## Overview

Retrieve statistical data for All Users Push (App Push). Supports filtering by Task ID and returns push statistics segmented by platform. The maximum query window is the most recent 30 days, and results are paginated.

### Request URL Example
``` html
https://xxxxxx/v4/timpush_query/statistics?usersig=xxx&identifier=admin&sdkappid=88888888&random=99999999&contenttype=json
```

### Query Parameters
| Parameter | Description |
| --- | --- |
| https | - Request protocol: HTTPS.<br>- Request method: POST. |
| xxxxxx | Dedicated domain based on the region associated with the SDKAppID.<br>- China: <code>console.tim.qq.com</code><br>- Singapore: <code>adminapisgp.im.qcloud.com</code><br>- Seoul: <code>adminapikr.im.qcloud.com</code><br>- Tokyo: <code>adminapijpn.im.qcloud.com</code><br>- Frankfurt: <code>adminapiger.im.qcloud.com</code><br>- Silicon Valley: <code>adminapiusa.im.qcloud.com</code><br>- Jakarta: <code>adminapiidn.im.qcloud.com</code><br>- Riyadh: <code>adminapiksa.im.qcloud.com</code> |
| v4/timpush_query/statistics | Request endpoint. |
| usersig | Signature generated by the App administrator account. See <a href="https://www.tencentcloud.com/document/product/1047/33517?lang=en&pg=">UserSig Backend API</a>. |
| identifier | Must be an App administrator account. For details, see <a href="https://www.tencentcloud.com/document/product/1047/33517?lang=en&pg=">App Administrator</a>. |
| sdkappid | The SDKAppID assigned when creating the app in the IM Console. |
| random | Random 32-bit unsigned integer (0 – 4294967295). |
| contenttype | Fixed value: json. |

### Rate Limit

Maximum 20 requests per second.

### Request Example
``` bash
{
    "StartTime": 1710000000,
    "EndTime": 1710600000,
    "TaskID": ["task_001", "task_002"],
    "Offset": 0,
    "Limit": 10
}
```

### Request Fields

|Field|Type|Required|Description|
|---------|---------|---------|---------|
|StartTime|Integer|Required|Query start time, Unix timestamp (seconds). The interval between StartTime and EndTime can be up to the most recent 30 days.|
|EndTime|Integer|Required|Query end time, Unix timestamp (seconds). Must be greater than StartTime.|
|TaskID|Array|Optional|List of push Task IDs, up to 5. If omitted, returns aggregated data for all tasks within the specified time range.|
|Offset|Integer|Optional|Pagination offset. Default is 0.|
|Limit|Integer|Optional|Number of records per page. Default is 20.|

### Response Fields
| Field | Type | Description |
| --- | --- | --- |
| ActionStatus | String | Result of the request:<br>- OK: Success<br>- FAIL: Failure |
| ErrorCode | Integer | Error code. 0 indicates success; non-zero indicates failure. |
| ErrorInfo | String | Error message. |
| Results | Array | Array of statistical results. Each element represents statistics for a push task. |
| TotalNum | Integer | Total number of task statistic records matching the query criteria. |
| IsCompleteFlag | Boolean | Indicates whether all data has been retrieved.<br>true: all data returned.<br>false: more data available, paginated |
| NextOffset | Integer | Offset value for the next request, used for pagination. |

#### Results Array Fields

|Field|Type|Description|
|---------|---------|---------|
|TaskID|String|Push task ID|
|TotalCount|Integer|Total number of push targets|
|SentCount|Integer|Actual number sent|
|DeliveredCount|Integer|Number of devices reached|
|ClickCount|Integer|Number of clicks|
|PlatformStatistics|Array|Array of statistics segmented by push platform|

#### PlatformStatistics Array Fields

|Field|Type|Description|
|---------|---------|---------|
|EventType|Integer|Push method. 1: Offline Push, 2: Online Push. If omitted, indicates aggregated statistics.|
|PushPlatform|Integer|Push platform. 1: APNS, 2: Xiaomi, 3: Huawei, 4: FCM, 5: Meizu, 6: OPPO, 7: vivo, 8: Honor, 9: HarmonyOS.|
|TotalCount|Integer|Total number of push targets for this platform|
|SentCount|Integer|Actual number sent for this platform|
|SentSuccCount|Integer|Number of successful sends for this platform|
|DeliveredCount|Integer|Number of devices reached for this platform|
|DeniedCount|Integer|Number of denials for this platform|
|ClickCount|Integer|Number of clicks for this platform|

## Error Codes

Unless a network error occurs (such as a 502 error), the HTTP status code for this API is always 200. **Actual error codes and error messages are provided in the ErrorCode and ErrorInfo fields of the response body.** For common error codes (60000 to 79999), refer to the [Error Codes](https://www.tencentcloud.com/document/product/1047/34348) documentation.

The following are private error codes for this API:

|Error Code|Description|
|---------|---------|
|90100|Invalid request parameters (JSON format error, StartTime greater than EndTime, more than 5 TaskIDs, etc.)|
|90102|Internal service error. Please try again later.|
