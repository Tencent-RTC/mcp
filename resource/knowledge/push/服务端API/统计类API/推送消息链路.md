## Overview

Retrieve the push trace data for a specific user within a designated All Users Push task. This API returns the complete push status for each device associated with the user, providing detailed information for every stage of the push flow—including Chat submission, Vendor Channel delivery, device arrival, user click, and more.

### Request URL Example
``` html
https://xxxxxx/v4/timpush_query/trace?usersig=xxx&identifier=admin&sdkappid=88888888&random=99999999&contenttype=json
```

### Query Parameters
| Parameter | Description |
| --- | --- |
| https | - Request protocol: HTTPS.<br>- Request method: POST. |
| xxxxxx | Dedicated domain name for your SDKAppID's region.<br>- China: <code>console.tim.qq.com</code><br>- Singapore: <code>adminapisgp.im.qcloud.com</code><br>- Seoul: <code>adminapikr.im.qcloud.com</code><br>- Tokyo: <code>adminapijpn.im.qcloud.com</code><br>- Frankfurt: <code>adminapiger.im.qcloud.com</code><br>- Silicon Valley: <code>adminapiusa.im.qcloud.com</code><br>- Jakarta: <code>adminapiidn.im.qcloud.com</code><br>- Riyadh: <code>adminapiksa.im.qcloud.com</code> |
| v4/timpush_query/trace | Request endpoint. |
| usersig | Signature generated by the App administrator account. See <a href="https://www.tencentcloud.com/document/product/1047/33517?lang=en&pg=">UserSig Backend API</a>. |
| identifier | Must be an App administrator account. For more information, see <a href="https://www.tencentcloud.com/document/product/1047/33517?lang=en&pg=">App Administrator</a>. |
| sdkappid | SDKAppID assigned by the Chat Console when creating the application. |
| random | Random 32-bit unsigned integer (range: 0 - 4294967295). |
| contenttype | Fixed value: json. |

### Rate Limit

Maximum 20 requests per second.

### Request Example
``` bash
{
    "TaskId": "task_001",
    "To_Account": "144115188075855872"
}
```

### Request Fields

|Field|Type|Required|Description|
|---------|---------|---------|---------|
|TaskId|String|Required|Push task ID.|
|To_Account|String|Required|Target user's account ID. Cannot be empty.|

### Response Fields
| Field | Type | Description |
| --- | --- | --- |
| ActionStatus | String | Result of request processing:<br>- OK: Success.<br>- FAIL: Failure. |
| ErrorCode | Integer | Error code. 0 indicates success; non-zero indicates failure. |
| ErrorInfo | String | Error message. |
| InstanceTrace | Array | List of push trace results for each device associated with the user. |

#### InstanceTrace Array Object Fields

|Field|Type|Description|
|---------|---------|---------|
|PushTime|String|Push time. Format: `YYYY-MM-DD HH:mm:ss`.|
|EventType|Integer|Push type. 1: Offline Push, 2: Online Push.|
|PushPlatform|Integer|Push platform. 1: APNS, 2: Xiaomi, 3: Huawei, 4: FCM, 5: Meizu, 6: OPPO, 7: vivo, 8: Honor, 9: HarmonyOS.|
|DeviceInfo|Object|Basic device information.|
|PushStatus|Object|Status for each stage of the push process.|

#### DeviceInfo Fields

|Field|Type|Description|
|---------|---------|---------|
|InstanceId|String|Device instance ID.|
|DeviceModel|String|Device model.|
|System|String|Operating system (iOS/Android/HarmonyOS).|
|SystemVersion|String|System version.|
|Token|String|Push Token.|
|CertId|String|Push Certificate ID.|
|SdkVersion|String|Chat SDK version.|
|PushVersion|String|Push Plugin version.|
|VendorInfo|String|Vendor information.|
|NotificationStatus|Integer|Notification permission status.|
|LastActiveTerminal|Integer|Last active terminal type.|
|Cappid|Integer|Sub-app ID (optional; returned only in multi-sub-app scenarios).|

#### PushStatus Fields

|Field|Type|Description|
|---------|---------|---------|
|IMCommitStat|Object|Chat submission status, includes IMStat subfields.|
|OfflinePushStat|Object|Offline Push status, includes OfflineStat, ChannelStat, DeviceStat, and ClickStat subfields.|
|OnlinePushStat|Object|Online Push status, includes ChannelStat, DeviceStat, and ClickStat subfields.|
|VendorPushInfo|Object|Vendor Push details, grouped by vendor (APNS/XiaoMi/HuaWei/FCM/Meizu/VIVO/OPPO/Honor/Harmony).|

#### PushStatInfo (Status Subfields for Each Stage)

|Field|Type|Description|
|---------|---------|---------|
|PushStatus|Integer|Push status. 1: Success, 2: Failure.|
|ErrorCode|Integer|Error code. 0 indicates success (convert to readable description via codedesc).|
|ErrorInfo|String|Error description (convert to readable description via codedesc).|
|EventTime|String|Event occurrence time.|

## Error Codes

Unless a network error occurs (e.g., HTTP 502), this API always returns HTTP 200. **Actual error codes and messages are provided in the ErrorCode and ErrorInfo fields of the response body.** For common error codes (60000–79999), refer to the [Error Codes](https://www.tencentcloud.com/document/product/1047/34348) documentation.

Private error codes for this API are listed below:

|Error Code|Description|
|---------|---------|
|90100|Invalid request parameters (e.g., JSON format error, TaskId empty, To_Account empty, etc.).|
|90102|Internal service error. Please try again later.|
