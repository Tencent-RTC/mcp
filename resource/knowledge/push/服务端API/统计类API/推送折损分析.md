## Overview

Retrieves loss analysis data for All Users Push (App Push). Supports filtering by Task ID and push platform. Returns the distribution of abnormal error codes for both the sending (ready-to-send) and delivery (post-send) stages. The maximum time range for queries is the past 7 days.

### Request URL Example
``` html
https://xxxxxx/v4/timpush_query/loss?usersig=xxx&identifier=admin&sdkappid=88888888&random=99999999&contenttype=json
```

### Query Parameters
| Parameter | Description |
| --- | --- |
| https | - Request protocol: HTTPS.<br>- Request method: POST. |
| xxxxxx | Dedicated domain name corresponding to the region of the SDKAppID.<br>- China: <code>console.tim.qq.com</code><br>- Singapore: <code>adminapisgp.im.qcloud.com</code><br>- Seoul: <code>adminapikr.im.qcloud.com</code><br>- Tokyo: <code>adminapijpn.im.qcloud.com</code><br>- Frankfurt: <code>adminapiger.im.qcloud.com</code><br>- Silicon Valley: <code>adminapiusa.im.qcloud.com</code><br>- Jakarta: <code>adminapiidn.im.qcloud.com</code><br>- Riyadh: <code>adminapiksa.im.qcloud.com</code> |
| v4/timpush_query/loss | Request endpoint. |
| usersig | Signature generated by the App administrator account. See <a href="https://www.tencentcloud.com/document/product/1047/33517?lang=en&pg=">UserSig Backend API</a>. |
| identifier | Must be an App administrator account. For more information, see <a href="https://www.tencentcloud.com/document/product/1047/33517?lang=en&pg=">App Administrator</a>. |
| sdkappid | SDKAppID assigned by the Chat Console when creating the application. |
| random | Random 32-bit unsigned integer, range: 0–4294967295. |
| contenttype | Fixed value: json. |

### Rate Limit

Maximum of 20 requests per second.

### Request Example
``` bash
{
    "StartTime": 1710000000,
    "EndTime": 1710600000,
    "TaskID": ["task_001"],
    "Platform": [1, 3]
}
```

### Request Fields

|Field|Type|Required|Description|
|---------|---------|---------|---------|
|StartTime|Integer|Required|Query start time in Unix timestamp (seconds). The time range between StartTime and EndTime can be up to 7 days in the past.|
|EndTime|Integer|Required|Query end time in Unix timestamp (seconds). Must be greater than StartTime.|
|TaskID|Array|Optional|List of push task IDs (up to 5). If not provided, the API returns aggregated loss data for all tasks in the specified time range.|
|Platform|Array|Optional|Filter by push platform. Platform enum values: 1=APNS, 2=Xiaomi, 3=Huawei, 4=FCM, 5=Meizu, 6=OPPO, 7=vivo, 8=Honor, 9=HarmonyOS. If omitted, returns data for all platforms. Only effective for platform-dimension loss data (`PlatformReadyToSendLoss`, `PlatformPostSendDeliveredLoss`).|

### Response Fields
| Field | Type | Description |
| --- | --- | --- |
| ActionStatus | String | Result of request processing:<br>- OK: Success.<br>- FAIL: Failure. |
| ErrorCode | Integer | Error code. 0 indicates success; non-zero indicates failure. |
| ErrorInfo | String | Error message. |
| Results | Array | Array of loss analysis results. Each element contains loss data for a specific push task. |

#### JSON Object Fields in the Results Array

|Field|Type|Description|
|---------|---------|---------|
|TaskID|String|Push task ID.|
|ReadyToSendLoss|Array|Sending side losses (aggregated): statistics on exceptions from Chat submission to vendor sending.|
|PostSendDeliveredLoss|Array|Delivery side losses (aggregated): statistics on exceptions from vendor sending to device delivery.|
|PlatformReadyToSendLoss|Array|Sending side losses by platform: distribution of sending exceptions by push platform.|
|PlatformPostSendDeliveredLoss|Array|Delivery side losses by platform: distribution of delivery exceptions by push platform.|

#### JSON Object (PushLoss) Fields in the Loss Arrays

|Field|Type|Description|
|---------|---------|---------|
|EventType|Integer|Push method. 1: Offline Push, 2: Online Push. Only returned in platform-dimension loss data.|
|PushPlatform|Integer|Push platform. 1: APNS, 2: Xiaomi, 3: Huawei, 4: FCM, 5: Meizu, 6: OPPO, 7: vivo, 8: Honor, 9: HarmonyOS. Only returned in platform-dimension loss data.|
|ErrCode|String|Error code (see codedesc for details).|
|ErrCount|Integer|Number of occurrences of this error code.|
|ErrInfo|String|Error description (see codedesc for details).|

## Error Codes

Unless a network error occurs (such as HTTP 502), the HTTP status code for this API is always 200. **Actual error codes and messages are provided in the** `ErrorCode` **and** `ErrorInfo` **fields of the response body.** For common error codes (60000–79999), refer to the [Error Codes](https://www.tencentcloud.com/document/product/1047/34348) documentation.

Private error codes for this API:

|Error Code|Description|
|---------|---------|
|90100|Invalid request parameters (e.g., JSON format error, StartTime greater than EndTime, TaskID exceeds 5, Platform enum value not between 1–9, etc.).|
|90102|Internal service error. Please try again later.|
