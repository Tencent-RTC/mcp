Feature Overview
- Push to the specified recipient account list, which should contain between [1, 500] accounts.

- Supports Online Channel, Manufacturer Channel (APNS, Huawei, Honor, OPPO, vivo, Xiaomi, Meizu, Google).

- Does not increment unread count by default.

   > **Note:**
   > 
   > This interface supports both Online Push and Offline Push. Online Push is supported only in SDK Version ≥ 8.2.6325.
   > 

## API Calling Description

### Sample request URL
``` html
https://xxxxxx/v4/timpush/batch?usersig=xxx&identifier=admin&sdkappid=88888888&random=99999999&contenttype=json
```

### Request parameters
| Parameter | Description |
| --- | --- |
| https | - Request protocol: HTTPS<br>- Request method: POST |
| xxxxxx | The dedicated domain corresponding to the country/region of your SDKAppID.<br>- China: <code>console.tim.qq.com</code><br>- Singapore: <code>adminapisgp.im.qcloud.com</code><br>- Seoul: <code>adminapikr.im.qcloud.com</code><br>- Tokyo: <code>adminapijpn.im.qcloud.com</code><br>- Frankfurt: <code>adminapiger.im.qcloud.com</code><br>- Silicon Valley: <code>adminapiusa.im.qcloud.com</code><br>- Jakarta: <code>adminapiidn.im.qcloud.com</code><br>- Riyadh: <code>adminapiksa.im.qcloud.com</code> |
| v4/timpush/batch | Request API |
| usersig | The Signature generated by the App admin account. For details, see <a href="https://www.tencentcloud.com/document/product/1047/34385">Generating UserSig</a> |
| identifier | You must be an App admin account. For more details, see <a href="https://www.tencentcloud.com/document/product/1047/33517">App Admins</a> |
| sdkappid | SdkAppid assigned by the Chat console when creating an app |
| random | A random 32-bit unsigned integer ranging from 0 to 4294967295 |
| contenttype | Fixed value: <code>json</code> |

### Sample request packets
``` bash
{
  "From_Account": "administrator",
  "To_Account": ["user1","user2"], // Array size range between [1,500]
  "MsgRandom": 3674128,
  "OfflinePushInfo": {
      "PushFlag": 0,  // 0 means offline push enabled, 1 means offline push disabled
      "Title": "Offline Push Title",
      "Desc": "Offline Push Content"
  }
}
```

> **Note:**
> This interface supports both Online Push and Offline Push. Online Push is supported only in SDK Version ≥ 8.2.6325.
> 

### Request packet fields
| Field | Type | Attribute | Description |
| --- | --- | --- | --- |
| From_Account | String | Required | Sender account, support UserID or RegistrationID. |
| To_Account | Array | Required | Target user account list, support UserID or RegistrationID. |
| MsgRandom | Integer | Required | 32-bit unsigned integer random number, with a value range from 0 to 4294967295<br>Backend uses message deduplication within the same second. <strong>Please ensure it is a random number</strong>. |
| OfflinePushInfo | Object | Required | Offline push notification configuration, please
| DataId | String | Optional | The customer's business custom identifier. This field will be passed through to the app backend during the callback. The field is limited to a maximum of 64 bytes. |

### Sample response packets

All successful:
``` bash
{
    "ActionStatus": "OK",
    "ErrorInfo": "",
    "ErrorCode": 0,
    "TaskId": "batch_667015d4_537529d8_2000005e80aa873_d03ac87_56f5e750"
}
```

All failed:
``` bash
{
    "ActionStatus": "FAIL",
    "ErrorInfo": "Invalid format of MsgRandom", // MsgRandom is invalid or not set
    "ErrorCode": 90001,
    "TaskId": ""
}
```

Partially successful:
``` bash
{
    "ActionStatus": "OK",
    "ErrorInfo": "",
    "ErrorCode": 0,
    "TaskId": "batch_667015d4_537529d8_2000005e80aa873_d03ac87_56f5e750",
    "ErrorList": [
        {
            "ErrorCode": 70107, // account does not exist
            "To_Account": "user"
        }
    ]
}
```

### Response packet field description
| Field | Type | Description |
| --- | --- | --- |
| ActionStatus | String | Request processing result:<br>- OK: means processing is successful.<br>- FAIL: processing failed. |
| ErrorCode | Integer | Error code. |
| ErrorInfo | String | Error message. |
| TaskId | String | Push task ID. |
| ErrorList | Object Array | Account list with sending failed. If all sent successfully, ErrorList is empty. |

Field description of the json Object in the ErrorList array

|Field|Type|Description|
|---------|---------|---------|
|To_Account|String|Target user account: UserID or RegistrationID.|
|ErrorCode|Integer|Error code.|
|ErrorInfo|String|Error description, which may be empty.|

## Error codes

Unless a network error occurs (e.g., a 502 error), the HTTP status code for this interface will always be 200.**The real error codes and messages are indicated in the response body by ErrorCode and ErrorInfo**. For common error codes (60000 to 79999), see the [Error Code](https://intl.cloud.tencent.com/document/product/1047/34348) document.

Private error codes for this API are as follows:

|Error code|Description|
|---------|---------|
|90001|Failed to parse the JSON format. Please ensure the request packet conforms to the JSON specification.|
|90009|The request requires App Administrator permissions.|
|90045|All-user/Tags/Single Push is Not Enabled.|
|90057|The provided DataId exceeds the maximum allowed length of 64 bytes.|
|91000|Internal service error, please try again.|
