The RTC Engine Top Up Package provides an additional, one-time block of usage minutes for your account. Purchase this package when your free minutes are exhausted or your monthly package does not cover your anticipated usage. Once added, the package minutes can be used for audio/video calls across all applications (SDKAppID) associated with your account (UIN). Each package is valid for one year from the purchase date.

You do not need an active monthly package to purchase or use a Top-Up Package. All account versions are eligible.

## Billing Information

Payment is prepaid and follows a buy-first, deduct-later model.
- The RTC Engine Top-Up Package is valid for one year from the purchase date. Any remaining minutes expire at the end of the validity period and are not refundable.

- The package operates at the UIN level, sharing the available balance across all applications (SDKAppID) under the same account.

- The package only offsets audio/video call usage. It does not cover Cloud Recording, Stream Mixing & Transcoding, AI services, or any other billable items.

- You can stack multiple packages. When multiple packages exist, deductions occur in order of expiry.

## Deduction Priority

If an account has multiple types of duration packages, usage is deducted in the following order of priority:

|Priority|Type|Description|
|---------|---------|---------|
|1 (Highest)|Free Duration Package|10,000 minutes are granted monthly and can be used for audio/video calls, Interactive Live Streaming, Cloud Recording, Stream Mixing & Transcoding, etc. Cleared at the end of each month.|
|2|Monthly Package Duration / RTC Engine Top-Up Package|Both are at the same level; deductions are made in order of expiry.|
|3 (Lowest)|Pay-as-you-go|Triggered automatically when no available duration package exists; billed daily based on actual usage.|

## How to Purchase
1. Log in to the [console](https://console.trtc.io/subscription) and go to the Package Subscription page. 

2. On the subscription page, select the RTC Engine sub-product, switch to the RTC Engine **Top-Up Package** tab, and click **Buy Now**.

   

3. Choose your preferred specification (25,000 / 250,000 / 1,000,000 minutes) and quantity. You can stack multiple packages of the same specification in a single order.

   

4. Check the agreement box, click **Buy Now**, submit your order, and complete the payment.

   

## Billing Example

User A uses up the monthly 10,000 free minutes and does not have an active monthly package. User A expects to use about 200,000 minutes of audio/video calls next. On April 1, 2026, User A purchases a 250,000-minute RTC Engine Top-Up Package.

Therefore:
1. User A makes a one-time payment of $225, and the package is valid until April 1, 2027.

2. From April 1, 2026, all audio/video call and Interactive Live Streaming usage will be deducted from this package until the balance is used up or the package expires.

3. When the package is exhausted or expires, if Pay-As-You-Go billing is enabled, the account will switch to pay-as-you-go mode. If not, service will be suspended.

## Notes
- The Top-Up Package can offset minutes consumed by the TRTC Audio/Video Subscription Service only. For usage calculation rules, see Audio/Video Duration Billing Description. The package cannot be used to supplement recording or stream mixing durations.

- After purchase, the Top-Up Package can offset audio/video call usage generated by any application (SDKAppID) under the same account (UIN).

- You may purchase multiple RTC Engine Top-Up Packages; there is no limit on quantity.

- Offset rates for the Top-Up Package are as follows: voice, HD, Ultra HD, 2K, and 4K consumption are offset at a ratio of 1 : 4 : 9 : 16 : 36, respectively. These rules match those of the monthly package duration. For details, see [Subscription Package Duration Billing Description](https://trtc.io/zh/document/59806).
